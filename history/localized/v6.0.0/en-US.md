### Plugin API 2.0
- Installing, updating, and enabling plugins no longer requires restarting poi, although Flash may need to be refreshed
- New plugins can prevent older application versions from running; update poi first
- New plugins can be updated directly under Settings → Extensions; plugin developers should consult the plugin development documentation in the GitHub Wiki
