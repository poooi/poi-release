### プラグイン API 2.0
- プラグインのインストール・更新・有効化に poi の再起動が不要に。ただし Flash の再読み込みが必要な場合があります
- 古い本体で新しいプラグインを使うと poi が動作しなくなるため、先に本体を更新してください
- 新しいプラグインは「設定－拡張機能」から直接更新可能。開発者は GitHub Wiki のプラグイン開発ドキュメントを参照してください

### 新機能
- 通知の履歴機能を追加。通知バーをクリックすると過去の通知を表示

### 修正
- 制空値の計算式を修正
- 月間の演習 7 回任務で poi が応答しなくなることがある問題を修正
- 任務カウントが正常に動作しないことがある問題を修正

### プラグイン更新
- 新プラグイン「kcwiki 语音字幕」を追加。艦娘の発言時に通知バーへ翻訳字幕を表示。公開時点では一部音声の誤りや取り違えが未修正
- [未卜先知] 艦名のクリックで装備を表示
- [秘书通知] ゲームから入渠音声が削除されたため、26 番の音声で代用
- [改修信息] 改修データを最新版に更新
