今後の開発・保守を容易にし、パフォーマンスを改善するため、多くのコードとアーキテクチャを再構築しました。

### プラグインの互換性
- プラグインを順次新しいアーキテクチャに移行。以後の機能追加、ゲームの新仕様への対応、修正は主に新版プラグインで提供
- 一部の新版プラグインは beta チャンネルで公開。「設定－拡張機能－詳細設定」で「beta 版プラグインを確認」を有効にして更新を確認可能
- 新しい poi は互換インターフェースにより旧プラグインを実行可能。古い poi では新プラグインを実行できません
- 6.3.0 以降の旧版は非互換なプラグインへの更新を防止し、インストール済みの場合は読み込みを拒否してロールバックを案内
- 6.2.x 以前には互換性チェックがありません。新版プラグインへの更新や poi 内からのインストールは避けてください。更新後に黒い画面になる場合は該当プラグインを削除し、旧版対応のオフラインパッケージをインストールしてください

### 新機能
- 終了時にメインパネルのデータを保存し、ゲームへのログイン前にもメインパネルや艦娘情報などのプラグインを閲覧可能
- 通知はゲームへのログイン後にのみ発生
- 「設定－表示設定」に Flash の画質設定を追加。変更時は Flash を再読み込み
- ツールバーのマップ情報で、通常海域のゲージ進捗も表示
- 補給でボーキサイトを消費した場合、通知バーに消費量を表示
- 受注中の任務記録を改善。他の端末で受注任務を変更した場合も古い任務を削除可能
- ゲージ破壊可能な海域に入った際、ウィンドウ内で最終形態を通知。この時点では各 EO とイベントの輸送以外の海域に対応
- プラグインの更新・クラッシュ通知をウィンドウ内通知に変更し、「通知設定－その他」の対象から除外

### プラグイン更新
- [未卜先知] 敵艦の CI が外れた場合にダメージが -1 と表示される問題を修正
- [远征信息] 中央欄の 3 艦隊にマウスを合わせると未達の遠征条件を表示し、出発警告にも具体的な条件を列挙
- [我变强了] 最新の API に対応
- [战斗记录] 過去の戦闘記録を表形式で表示。初回起動時に旧記録を整理し、終了予定時刻を表示
- [舰娘信息] 対潜データを追加
