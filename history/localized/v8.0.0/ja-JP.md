### 2017 秋イベントへの対応
- マップと札の FCD データを更新
- 対潜哨戒機のアイコンを追加
- 新しい戦闘 API に対応し、任務カウントと航海日誌の記録を修正
- 遊撃部隊の退避表示に対応
- 大破進撃の判定方法を変更し、連合艦隊の随伴艦隊旗艦が大破した場合も警告を表示
- 海域の札警告の判定方法を変更し、通常艦隊では出撃していないすべての艦隊を確認対象に変更
- 索敵の 33 式を 7 隻編成に対応させるよう拡張

### 新機能
- React 16 に更新
- プラグインのクラッシュ処理を改善。本体に影響を及ぼさず、エラー情報を報告しやすいように変更
- プラグイン名の直接入力によるインストールの入力ミス対策を強化
- [Windows] 半透明背景に対応。高いマシン性能を必要とするため、環境に応じて有効にしてください
- プラグインの詳細設定に `自動修復` を追加し、一部のインストール失敗やプラグインのエラーを修復可能
- [Linux] 自動更新に対応
