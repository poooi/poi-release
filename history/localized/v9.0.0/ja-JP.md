### 艦これ第二期への対応
- API の変更に対応
- 海域マップを更新
- 同梱の Flash を削除
- 既定の解像度を 1200x720 に変更

### 新機能
- ウィンドウプラグインの仕組みを刷新
  - 本体内のプラグインとウィンドウプラグインを相互に切り替え可能
  - ウィンドウプラグインをバックグラウンドに常駐させず、システムリソースを節約
- 解像度を固定していない場合、編集モードでゲーム画面の表示比率を調整可能
  - 編集モードのボタンはゲーム画面左下の `>` をクリックすると表示
  - 編集モードでゲーム画面の端をダブルクリックすると、ウィンドウの高さまたは幅に合わせて調整
- ゲーム画面を独立したウィンドウとして表示可能
- パネルのオーバーレイ表示に対応
- 対空噴進弾幕に対応
- Electron 3.0 に更新
- FontAwesome5 に更新

### 修正
- 一部のパネルが拡大時に正しく表示されない問題を修正
- 上流の問題により macOS High Sierra でタイトルバーを非表示にできなくなっていた機能を復旧
