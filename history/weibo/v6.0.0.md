### 插件 API 2.0
- 安装、更新和启用插件不再需要重启 poi，但可能需要刷新 Flash
- 旧版本本体使用新版本插件会导致 poi 无法运行，请先更新本体
- 新版插件可以在“设置－扩展程序”中直接更新；插件开发者请查阅 GitHub Wiki 的插件开发文档

### 功能
- 增加消息历史记录功能，点击消息栏即可弹出历史记录

- 修复月常 7 次演习可能导致 poi 卡死的问题
