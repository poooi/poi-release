本版重写了大量代码、调整架构，以便后续开发维护并提高性能。

### 插件兼容性
- 插件逐步迁移到新架构，后续功能、游戏新机制支持和修复主要提供给新版插件
- 部分新版插件发布在 beta 渠道，可在“设置－扩展程序－高级设置”启用“检查 beta 版插件”后检查更新
- 新版 poi 提供兼容接口运行旧插件；旧版 poi 无法运行新插件
- 6.3.0 及之后的旧版会阻止不兼容的插件升级，对已安装的不兼容新版拒绝加载并提供回滚
- 6.2.x 及更早版本缺少兼容性检查，请勿升级新版插件或通过 poi 内部安装插件；升级后黑屏时需移除对应插件，再安装适用于旧版的离线插件包

### 功能
- 关闭 poi 后保存主面板数据，未登录游戏时也能查看主面板及舰娘信息等插件内容
- 提示通知只在登录游戏后触发
- 在“设置－显示设置”增加 Flash 画质调整，修改时重新载入 Flash
- 工具栏地图提示在普通海域血条图也显示血条进度
- 补给消耗铝时，在通知栏显示消耗量
- 改进活动任务记录：在其他设备修改活动任务后，也能移除旧任务
- 增加斩杀提醒：进入可能斩杀的地图时弹出窗口内通知，当时支持各 EO 和活动的非运输图
- 插件更新与插件崩溃改用窗口内通知，不受“通知设置－其它”控制

### 插件更新
- [未卜先知] 修复敌舰 CI 未命中时伤害量显示为 -1 的问题
- [远征信息] 鼠标移到中间栏三个舰队上时，显示不满足的远征条件；出发警告框也列出具体条件
- [我变强了] 适配最新版本 API
- [战斗记录] 用表格列出历史战斗记录；首次打开会整理旧记录并显示预计结束时间
- [舰娘信息] 增加反潜数据
