### 功能
- 支持不同装备加成系数的 33 式索敌公式，可在舰队面板查看
- 增加舰娘和舰队速度显示
- 可在设置中关闭最终战提示
- 更新部分装备图标，支持 2017 冬活新装备
- 优化游戏区域缩放机制
- 增加插件自动更新，可在插件设置面板开启
- 优化 FCD 数据更新机制
- 增加安全模式，插件不会自动启用；可使用命令行 --safe 或 -S，或设置中的“下次启动进入安全模式”
- 支持调节面板区域最小宽度或高度，以获得更大的面板区域
- [Linux] 增加托盘图标支持，可在设置中关闭
- [Windows] 勾选启动时建立快捷方式后，也会创建 poi (safe mode) 快捷方式

### 修复
- 修正网络重试次数为负数时的网络错误，以及为 0 时仍显示重试信息的问题
- 清华插件源关闭，自动把原使用清华源的用户迁移至其他源

### 插件更新
- 修正非第一舰队参加演习时，未卜先知无法正确判断参演舰队的问题
- [舰娘信息] 移除排序设置区域，将当前排序信息显示在列表表头；修正排序使其与游戏内一致
- [舰娘信息] 类型大类支持复选，增加“别的舰娘”分类，便于寻找水母、潜母、补给舰、扬陆舰和工作舰
- [舰娘信息] 增设补强装备使用与本体一致的提示，支持显示舰娘所在舰队
- [舰娘信息] 可切换裸装数值／含装备加成数值，以及单页／分页显示
- [舰娘信息] 增加“在舰队中”“战意高昂”“增设补强”筛选，使用本体 FCD 数据进行出击限定筛选
- [舰娘信息] 增加重置全部筛选与显示设置的按钮，支持自定义 CSS 和缩放系数，修正每 HP 维修所需时间
- [经验计算] 修正竖版布局；同等级舰娘按剩余升级经验值升序排列
- [远征信息] 修复大发动艇加成计算和显示，增加鬼怒改二、特大发动艇加成计算支持，显示部分未满足条件的具体原因
- [未卜先知] 下一点信息显示上次战斗阵型，战斗中显示敌我舰队名及敌舰火力、雷击、对空、装甲，可在设置中开关
